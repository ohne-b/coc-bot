# Security

Report suspected vulnerabilities privately through
[GitHub security advisories](https://github.com/ohne-b/coc-bot/security/advisories/new).
Include the affected commit, impact, reproduction steps and redacted evidence. Do not
open a public issue containing credentials, device/API keys or an exploitable secret.

Only the current development branch is maintained. There are no supported desktop
releases yet. The inherited dashboard/relay is retained as migration reference; do not
assume it has been security-audited or expose it to untrusted networks.

Ordinary recognition and farming problems belong in the bug-report issue template.
